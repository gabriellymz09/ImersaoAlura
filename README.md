## 📖 Visão Geral

Este repositório reúne aplicações práticas voltadas ao aprendizado de lógica de programação, arquitetura de software, automações em **Python** e desenvolvimento web moderno (**HTML, CSS, JavaScript e React**), mantendo uma identidade visual padronizada e acolhedora em tons de rosa (*Pink Edition*).

O objetivo principal foi vivenciar o ciclo de evolução de software:
1. **Fundamentos sólidos:** Algoritmos, condicionais e estruturas matemáticas puras.
2. **Modularização e Arquitetura:** Funções reutilizáveis, boas práticas e bibliotecas nativas.
3. **Interfaces Amigáveis:** De utilitários CLI a GUIs em Tkinter e interfaces web reativas.
4. **Qualidade de Código:** Testes automatizados unitários e persistência client-side.

## 🚀 Resumo das Aulas e Projetos Desenvolvidos

### 🐍 Aula 1: Calculadora Python Pink Edition (Fundamentos & Lógica)

Uma suíte completa de scripts em Python desenvolvida para fixar os fundamentos da programação, indo desde comandos elementares até interfaces gráficas e utilitários matemáticos de precisão.

#### 📌 Versões Criadas:

| Script | Conceitos Chave | Descrição |
|---|---|---|
| `calculadora_basica.py` | `input()`, `float()`, `if/elif/else` | Operações aritméticas básicas com validação simples de divisão por zero. |
| `calculadora_modular.py` | `def`, `return`, `while True` | Código limpo em funções reaproveitáveis, com menu interativo e repetição contínua. |
| `calculadora_cientifica.py` | `import math`, radianos, log | Operações avançadas: potências, radiciação, seno, cosseno, tangente e logaritmos. |
| `calculadora_rosa_gui.py` | `tkinter`, grid, event handling | Interface desktop interativa em tons pastéis de rosa, com feedback sonoro e visual. |
| `calculadora_escalas_e_medidas.py` | Proporções, SVG, conversão | Estúdio avançado para conversão de grandezas físicas e cálculo de escalas arquitetônicas/cartográficas. |

---

### 🌐 Aula 2: Interface Web em React (Frontend Moderno)

- **Tecnologias:** React 19, TypeScript, Tailwind CSS, Lucide Icons.
- **Objetivo:** Traduzir a lógica de cálculo e utilitários para uma experiência web interativa, componentizada, responsiva e fluida no navegador.
- **Destaques:**
  - Componentização modular de cards e botões táteis.
  - Alternância de ferramentas em abas e transições suaves.
  - Responsividade total para desktops, tablets e dispositivos móveis.

---

### 📝 Aula 3: Minha Lista de Tarefas (To-Do List Dinâmica)

Uma aplicação web completa de gerenciamento de tarefas estruturada em HTML5 semântico, CSS3 e JavaScript puro, focada em boas práticas de manipulação do DOM e experiência do usuário.

#### ✨ Destaques do Projeto:
- **Identidade Visual:** Tema em tons de rosa, tipografia *Poppins* e diferenciação inteligente de tarefas pendentes vs. concluídas.
- **Persistência de Dados:** Integração com o `localStorage` do navegador para manter as tarefas salvas automaticamente mesmo após atualizar a página.
- **Filtros e Contadores:** Visualização dinâmica de todas as tarefas, apenas pendentes ou apenas concluídas.
- **Testes Automatizados:** Suíte de testes unitários integrada utilizando o executor nativo do Node.js (`node:test` e `node:assert`), garantindo confiabilidade nas funções puras de adição, remoção e alternância de status.

## 🛠️ Como Executar os Projetos

### Pré-requisitos
- [Python 3.10+](https://www.python.org/downloads/)
- [Node.js 18+](https://nodejs.org/)

---

### 1️⃣ Executando os Scripts Python (Aula 1)

Abra o seu terminal na pasta correspondente e execute o script desejado:

```bash
# Navegar até a pasta da aula 1 (ou execute a partir da raiz)
cd aula1

# Executar a versão básica
python calculadora_basica.py

# Executar a versão modular interativa
python calculadora_modular.py

# Executar a versão científica
python calculadora_cientifica.py

# Executar a versão gráfica desktop (Tkinter)
python calculadora_rosa_gui.py

# Executar o estúdio de escalas e medidas
python calculadora_escalas_e_medidas.py
```

---

### 2️⃣ Executando a Aplicação React (Aula 2)

```bash
# Navegar até a pasta da aula 2
cd aula2

# Instalar dependências
npm install

# Iniciar servidor local de desenvolvimento
npm run dev
```

Abra `http://localhost:3000` no seu navegador para ver a interface em funcionamento.

---

### 3️⃣ Executando e Testando a To-Do List (Aula 3)

#### Rodando a aplicação web:
Basta abrir o arquivo `aula3/index.html` em qualquer navegador web moderno (ou utilizar a extensão *Live Server* no VS Code).

#### Rodando a suíte de testes automatizados:
Na pasta referente à Aula 3, execute o executor nativo de testes do Node.js:

```bash
# Navegar até a pasta da aula 3
cd aula3

# Executar os testes unitários
node tests.js
```

Exemplo de saída esperada dos testes:
```text
✔ deve adicionar uma nova tarefa com id único e status pendente (1.2ms)
✔ deve marcar uma tarefa pendente como concluída (0.4ms)
✔ deve alternar o status de uma tarefa concluída para pendente (0.3ms)
✔ deve remover uma tarefa corretamente pelo id (0.3ms)
✔ deve persistir e carregar o estado corretamente no armazenamento (0.5ms)
ℹ tests 5
ℹ suites 0
ℹ pass 5
ℹ fail 0
```
